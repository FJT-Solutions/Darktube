# Sessões e Cookies de Redes Sociais

Esta pasta armazena com segurança os cookies e tokens das suas contas:
- `tiktok_cookies.json`: Sessão web do TikTok Creator Studio
- `instagram_session.json`: Sessão autenticada do Instagram / Facebook
- `pinterest_cookies.json`: Sessão web do Pinterest
- `kwai_cookies.json`: Sessão web do Kwai Creator Center
- `threads_cookies.json`: Sessão web do Threads
- `youtube_client_secrets.json` e `youtube_credentials.json`: OAuth da Google API em modo teste

> **Segurança:** Todos os arquivos desta pasta são automaticamente ignorados pelo Git (`.gitignore`).
> Nunca compartilhe esses arquivos publicamente.
